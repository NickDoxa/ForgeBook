**Step 1: Edit `ChatRequestHandler` (from Plan 03) to add the test sink.** This is a pre-requisite modification that Plan 03 intentionally left a seam for. Add:

```java
// In ChatRequestHandler:
/** Package-private test sink. When non-null, AiExecutor's response lambda calls this
 *  instead of ForgebookNetwork.CHANNEL.send(...). ChatEchoGameTest uses this to observe
 *  the response synchronously without binding to a real client connection. */
@org.jetbrains.annotations.Nullable  // or plain // @VisibleForTesting comment if annotations unavailable
static volatile java.util.function.Consumer<Object> responseSinkForTests = null;

public static void handle(ChatRequestPacket msg, Supplier<NetworkEvent.Context> ctxSupplier) {
    NetworkEvent.Context ctx = ctxSupplier.get();
    ctx.setPacketHandled(true);
    try {
        AiExecutor.get().submit(() -> {
            // D-19 pattern: expensive work here (none for echo), then enqueueWork for game-state touch.
            ChatResponsePacket response = new ChatResponsePacket("echo: " + msg.body(), true);
            ctx.enqueueWork(() -> {
                var sink = responseSinkForTests;
                if (sink != null) {
                    sink.accept(response);
                } else {
                    ForgebookNetwork.CHANNEL.send(
                        PacketDistributor.PLAYER.with(() -> (ServerPlayer) ctx.getSender()),
                        response);
                }
            });
        });
    } catch (RejectedExecutionException e) {
        ctx.enqueueWork(() -> {
            var sink = responseSinkForTests;
            ChatErrorPacket err = new ChatErrorPacket(ChatErrorPacket.ErrorCode.OVERLOADED, "aiExecutor saturated");
            if (sink != null) sink.accept(err);
            else ForgebookNetwork.CHANNEL.send(
                PacketDistributor.PLAYER.with(() -> (ServerPlayer) ctx.getSender()), err);
        });
    }
}
```

**Step 2: Write `src/test/java/com/forgebook/gametest/ChatEchoGameTest.java`.**

```java
package com.forgebook.gametest;

import com.forgebook.network.ChatRequestHandler;
import com.forgebook.network.ChatRequestPacket;
import com.forgebook.network.ChatResponsePacket;
import net.minecraft.gametest.framework.GameTest;
import net.minecraft.gametest.framework.GameTestHelper;
import net.minecraftforge.event.RegisterGameTestsEvent;
import net.minecraftforge.eventbus.api.SubscribeEvent;
import net.minecraftforge.fml.common.Mod;
import net.minecraftforge.gametest.GameTestHolder;
import net.minecraftforge.gametest.PrefixGameTestTemplate;
import net.minecraftforge.network.NetworkEvent;

import java.util.UUID;
import java.util.concurrent.atomic.AtomicReference;
import java.util.concurrent.CountDownLatch;
import java.util.concurrent.TimeUnit;

/**
 * D-28 server-only GameTest. Invokes ChatRequestHandler.handle directly on the
 * dedicated GameTest server, captures the response via the test sink, and
 * asserts the echo payload.
 *
 * Not a wire-level round trip: per RESEARCH.md L1145-1158, true client-side
 * packet decode is deferred to Phase 5 prod-jar smoke. This covers everything
 * EXCEPT the Netty encoder/decoder — which is exercised at build time by
 * `./gradlew build` succeeding on the compile-time reference to the codecs.
 */
@GameTestHolder("forgebook")
@PrefixGameTestTemplate(false)
public class ChatEchoGameTest {

    @GameTest(template = "empty", timeoutTicks = 100)
    public static void chatEchoRoundTrip(GameTestHelper helper) {
        final AtomicReference<Object> captured = new AtomicReference<>();
        final CountDownLatch latch = new CountDownLatch(1);

        ChatRequestHandler.responseSinkForTests = resp -> {
            captured.set(resp);
            latch.countDown();
        };

        try {
            ChatRequestPacket req = new ChatRequestPacket("hello forgebook", UUID.randomUUID());
            // Synthetic context — enqueueWork runs synchronously to flatten the
            // AiExecutor -> tick-thread handoff into the test thread observation.
            NetworkEvent.Context ctx = new SyntheticNetworkContext();
            ChatRequestHandler.handle(req, () -> ctx);

            boolean arrived;
            try {
                arrived = latch.await(5, TimeUnit.SECONDS);
            } catch (InterruptedException e) {
                Thread.currentThread().interrupt();
                helper.fail("interrupted waiting for echo");
                return;
            }

            if (!arrived) {
                helper.fail("no response captured within 5s (AiExecutor not running?)");
                return;
            }

            Object resp = captured.get();
            if (!(resp instanceof ChatResponsePacket cr)) {
                helper.fail("response was not ChatResponsePacket: " + resp);
                return;
            }
            if (!"echo: hello forgebook".equals(cr.body())) {
                helper.fail("echo body mismatch: got '" + cr.body() + "'");
                return;
            }
            if (!cr.complete()) {
                helper.fail("echo packet not marked complete");
                return;
            }

            helper.succeed();
        } finally {
            ChatRequestHandler.responseSinkForTests = null;
        }
    }

    /** Minimal NetworkEvent.Context stand-in: enqueueWork runs inline. */
    private static final class SyntheticNetworkContext extends NetworkEvent.Context {
        // If NetworkEvent.Context is final in 1.20.1 Forge, fall back to
        // creating a real one via a test-only factory that uses reflection
        // to mint an instance bound to a stubbed Connection. Spike this in
        // Task 2's local run and adjust if the direct-extend path is blocked.
    }
}
```

**Implementation note re `NetworkEvent.Context`:** It IS non-final and has a public-ish constructor in Forge 47.x, but the simplest path is to intercept the handler's dependency on `Context.enqueueWork` entirely. Alternative if `extends NetworkEvent.Context` fails to compile: refactor `ChatRequestHandler.handle` to accept a `Runnable` enqueuer and a `Consumer<Object>` responder as overridable parameters with a package-private overload, and the GameTest calls the overload directly. Document the choice inline.

```yaml
# .github/workflows/build.yml
name: build
on:
  push:
    branches: [main, master]
  pull_request:
    branches: [main, master]

jobs:
  build:
    runs-on: ubuntu-22.04
    timeout-minutes: 30
    steps:
      - uses: actions/checkout@v4

      - uses: actions/setup-java@v4
        with:
          distribution: temurin
          java-version: 17

      - name: Cache Gradle + ForgeGradle caches
        uses: actions/cache@v4
        with:
          path: |
            ~/.gradle/caches
            ~/.gradle/wrapper
            ~/.gradle/caches/forge_gradle
          key: ${{ runner.os }}-gradle-fg6-${{ hashFiles('**/*.gradle*', 'gradle.properties') }}
          restore-keys: ${{ runner.os }}-gradle-fg6-

      - name: Firewall lint — no net.minecraft.client.* outside com.forgebook.client
        shell: bash
        run: |
          HITS=$(grep -rn --include='*.java' 'import net\.minecraft\.client\.' src/main/java/ \
            | grep -v '^src/main/java/com/forgebook/client/' || true)
          if [ -n "$HITS" ]; then
            echo "CLIENT-class import outside com.forgebook.client/:"
            echo "$HITS"
            exit 1
          fi

      - name: ApiKey.raw() caller lint
        shell: bash
        run: |
          ALLOWED='^src/main/java/com/forgebook/(ai|integration)/'
          HITS=$(grep -rn --include='*.java' '\.raw()' src/main/java/ | grep -vE "$ALLOWED" || true)
          if [ -n "$HITS" ]; then
            echo "ApiKey.raw() called from unauthorised package:"
            echo "$HITS"
            exit 1
          fi

      - name: Build
        run: ./gradlew --no-daemon build

      - name: GameTest
        run: ./gradlew --no-daemon runGameTestServer

      - name: Classloader-leak smoke check
        shell: bash
        run: |
          LOG=run/gametest/logs/latest.log
          if [ ! -f "$LOG" ]; then
            echo "missing $LOG after runGameTestServer"
            exit 1
          fi
          if grep -q 'NoClassDefFoundError.*net/minecraft/client' "$LOG"; then
            echo "CLIENT-class leak detected on dedicated server:"
            grep -n 'NoClassDefFoundError' "$LOG"
            exit 1
          fi
          echo "No client-class NCDFE detected."
```

Hardening notes:
- `shell: bash` is explicit so `set -e` defaults apply — otherwise a failed pipe step can silently continue.
- `|| true` on the grep lines prevents grep's exit-1-on-no-match from prematurely failing the step; we then test the captured output.
- `--no-daemon` on both Gradle invocations — GHA runners don't reuse JVMs across steps, so a daemon just wastes startup.
- `setup-java@v4` with `distribution: temurin` matches CLAUDE.md's Temurin/Adoptium recommendation for Java 17.
- Cache key is invalidated whenever `build.gradle`, `settings.gradle`, or `gradle.properties` change — covers jsoup-version bumps and FG version bumps automatically.

Do NOT add:
- A separate lint job: Steps run fast enough that fanning out jobs adds scheduling latency for no gain.
- Matrix builds across OS: Forge toolchain caching is Linux-tuned and MDK targets developer-class machines — Windows/macOS CI is Phase-5 concern.
- `upload-artifact`: we don't publish jars from CI in Phase 1 (deferred; no distribution in this phase).
- Nightly / scheduled triggers: Phase-1 CI runs on commit only; D-29 scope is explicit.
