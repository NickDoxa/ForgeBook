<objective>
Create the repo-root `README.md` that teaches a first-time server owner everything needed to install, configure, and trust ForgeBook before first use. Verify (but do NOT modify) the existing `LICENSE` (MIT) and `THIRD_PARTY_NOTICES.md` (jsoup MIT, verified at jsoup.org/license 2026-04-16). REL-03 mandates these three artifacts collectively.

Security-posture bullets (from RESEARCH §README L464-482):
- API calls originate server-side via java.net.http.HttpClient
- Client-side code firewalled: com.forgebook.client.* cannot import com.forgebook.ai.* / com.forgebook.safety.* / com.forgebook.config.ApiKey
- SafeHttpFetcher refuses http://, private-IP, loopback, >1 MB (SSRF guard)
- forgebook-server.toml contains plaintext keys → chmod 600 (Linux/macOS) or NTFS ACL (Windows)
- Log4j2 ApiKeyScrubFilter redacts Authorization / x-api-key / sk-ant- / sk-proj-
- Defaults (op_only=true, 5 req/min per player) prevent a single malicious player draining API budget

License/credits links point to existing files (verified unchanged).

| README → server operator's decisions | Misleading security advice (e.g., wrong `chmod` syntax) could leave an API key world-readable, leading to a real-world API-key theft. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-05-02-01 | Information Disclosure | `chmod 600` prose in README | mitigate | Include the exact command `chmod 600 config/forgebook-server.toml` as a code-block (not prose) so operators can copy-paste without typos. Acceptance criteria greps for the exact string. |
| T-05-02-02 | Information Disclosure | Windows NTFS-ACL guidance | mitigate | Windows has no `chmod`; provide a one-line note in the Security Posture section: "On Windows, set the file's NTFS ACL so only the server-running account can read." Do NOT give a wrong PowerShell command — prose suffices; operators already versed in Windows server admin will know how. |
| T-05-02-03 | Repudiation | jsoup attribution | mitigate | README links to THIRD_PARTY_NOTICES.md in a Credits section; combined with mods.toml `credits` field (plan 05-01) this satisfies the MIT "permission notice shall be included" obligation in-repo, in-manifest, and in-UI. |
