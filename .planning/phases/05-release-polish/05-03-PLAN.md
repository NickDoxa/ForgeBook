<objective>
Expand `src/main/resources/assets/forgebook/lang/en_us.json` from the current 21-key baseline (Phase 4 UI keys) to 47 total keys by adding 26 new `forgebook.command.*` keys that Plan 05-04 will reference from refactored Java call sites. This plan ships the JSON resource only; the Java refactor happens in parallel Plan 05-04 (same wave, no file overlap).

Purpose: Minecraft's `Component.translatable(key)` resolves translation keys at client render time via this single file. The server-side command refactor (Plan 05-04) will emit translation keys (not prose) through `sendSuccess` / `sendFailure` — if those keys are missing from en_us.json, clients see raw key strings like `forgebook.command.reload.success` in chat instead of the translated prose. This plan prevents that.
