<objective>
Build the RAG single-shot pipeline that powers `/forgebook item`: take a (modId, itemId, Optional<URL>) tuple, authorize, fetch the mod's docs URL through `SafeHttpFetcher`, scrape + frame it via `ModDocsScraper` + `PromptFraming`, and issue ONE provider.chat(...) with empty tools[] (no AgentLoop). Append the source URL to the reply for CMD-07 citation. Emit audit log lines at every terminal path.

Purpose: `/forgebook item` must be deterministic, cheap, and bounded. A tool-using agent turn would waste 1-2 provider calls when the URL is already known. Single-shot RAG is 1 fetch + 1 provider call, with `tools = List.of()` guaranteeing Anthropic cannot return `stop_reason = "tool_use"`.
Output: `src/main/java/com/forgebook/ai/RagItemPipeline.java` + unit test scaffold exercising auth / missing-URL / fetch-fail / provider-error / happy-path branches. This plan does NOT wire the Brigadier command — that's Plan 06's job. This plan only produces the callable pipeline.
</objective>
