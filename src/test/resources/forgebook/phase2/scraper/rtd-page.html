Configuration is read from the forgebook-server.toml file located in the server's config directory. This file is automatically generated on first run with sensible defaults. The configuration supports hot-reload via the /forgebook reload command without restarting the server. All server-side settings are stored here, including API keys, rate limits, and feature toggles. The ai_provider field accepts ANTHROPIC, OPENAI, or OLLAMA as values. When using ANTHROPIC, you must set ai_api_key to a valid Claude API key obtained from console.anthropic.com. The ai_model field defaults to claude-haiku-4-5 but can be changed to any model supported by your provider. Rate limiting is configured via rate_limit_per_minute and applies per player UUID. Setting op_only to true restricts the mod to server operators only. The enable_web_search flag controls whether the web_search tool is available to the AI agent. When disabled, the agent falls back to only using installed mod documentation. The curseforge_modpack_id and curseforge_api_key fields enable modpack context enrichment.
